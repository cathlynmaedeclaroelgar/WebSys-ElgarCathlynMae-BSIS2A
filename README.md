## Weekly Summary

### Week 1 - HTML Fundamentals
Created the initial HTML page layout using foundational elements such as headers, paragraphs, and text formatting to establish basic web page structuring.

### Week 2 - Semantic & Multimedia
Utilized semantic HTML layout tags along with embedded multimedia features, including hero images and video players for dynamic content presentation.

### Week 3 - CSS Basics
Applied external CSS styles to design custom layouts, navigation links, content cards, styled buttons, form controls, and structured section containers.

### Week 4 - JavaScript Basics and DOM Manipulation
Implemented interactive JavaScript features, including a real-time clock header display, dynamic light/dark theme switching, and an active To-Do list manager.

### Week 5 - Javascript Functions and Bootstrap
Built a responsive portfolio interface using Bootstrap 5, featuring a top navigation bar, full-width carousel, service cards, interactive buttons, and a structured footer.

### Week 6 - API & Client Storage
Developed a multi-feature web application demonstrating client-side storage (localStorage for name saving and user preferences) alongside REST API integrations (OpenWeatherMap Weather Checker, GitHub User Lookup, and Google Maps).

### Week 7 - MiniFullStackStarter
Created a mini full-stack user management system supporting real-time data submission, dynamic list rendering, and record deletion capabilities.
URL of the Live Render Link for the deployed system: https://week7-fullstackstarter-d10u.onrender.com
